## Langkah Pengerjaan
1. Membuat file Dockerfile dan index.html
2. Build image:
   docker build -t profil-alifahwindykhairiya:1.0 .
3. Menjalankan container:
   docker run -d --name profil-alifahwindykhairiya -p 8082:80 profil-alifahwindykhairiya:1.0
4. Mengecek hasil di browser: localhost:8082
5. Upload ke GitHub
